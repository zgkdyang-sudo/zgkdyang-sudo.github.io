Agent Security · Research

Provably Lossless and Robust Agent Watermarking

First proposed a provably lossless and robust agent watermarking framework. By combining forensic branching design with redundant behavioral watermarking, the approach guarantees zero impact on an agent's normal task performance while ensuring watermark robustness against attacks. It addresses the practical challenge of copyright protection in agent repackaging scenarios.
